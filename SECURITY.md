# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

To report security vulnerabilities, please contact the maintainer via GitHub security advisories or open an issue at https://github.com/nurfarhad/figma-block-mosaic/issues. Please do not report sensitive vulnerabilities in public discussion before a patch is prepared.

Block Mosaic intentionally has no network permission, accounts, analytics, or external dependencies. Changes that add any of these should receive a dedicated security and privacy review.
