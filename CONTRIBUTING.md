# Contributing

Issues and pull requests are welcome after the GitHub repository URL is published.

1. Fork and clone the repository.
2. Import `manifest.json` as a development plugin in the Figma desktop app.
3. Make a focused change.
4. Run `npm run validate` with Node.js 20 or newer.
5. Test creating and updating a mosaic in Figma.
6. Open a pull request describing the behavior change and manual test results.

Please do not add analytics or network access without also updating the manifest, privacy policy, Community disclosure, and documentation.
