# Privacy policy for Block Mosaic

Last updated: August 17, 2026

Block Mosaic does not collect, transmit, sell, or share personal information or document content.

The plugin runs locally inside Figma and has network access disabled in its manifest. It does not use analytics, advertising, external APIs, cookies, accounts, or remote storage.

To make generated mosaics editable later, the plugin stores the selected mosaic settings—cell size, density, accent ratio, seed, and colors—as Figma plugin data on the generated frame. This information remains within the user's Figma document and is governed by the user's relationship with Figma. Removing the generated frame removes that stored plugin data.

If the plugin's behavior changes in a future release, this policy should be updated before that release is published.
