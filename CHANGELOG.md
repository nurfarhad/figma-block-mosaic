# Changelog

All notable changes to Block Mosaic will be documented here.

## [1.0.0] - 2026-08-17

### Added

- Deterministic block mosaic generation.
- Controls for cell size, density, accent ratio, seed, and three colors.
- Live canvas regeneration with debounced controls.
- Wand-style seed randomizer and dedicated close control.
- Hex and opacity editing for all three colors.
- Safe in-place updates for frames created by Block Mosaic.
- Relaunch button support.
- Explicit no-network manifest permission.
